# 단어정원 · Word Garden

아이폰 홈 화면에 설치할 수 있는 개인용 영어 학습 PWA입니다. 별도 로그인, 앱 서버, 유료 AI API 없이 동작합니다. 흰색·연회색 바탕, 선명한 파란색 강조, 큰 제목과 단순한 카드로 학습에 집중하도록 구성했습니다.

[단어정원 접속](https://wordgarden-personal-static.onrender.com/)

## 학습 콘텐츠

| 구분 | 이전 | 현재 |
|---|---:|---:|
| 사전 표제어 | 6,000 | 9,250 |
| 단어·표현 예문 | 10,060 | 15,492 |
| 한영 번역 문장 | 2,000 | 3,000 |
| 연구실 필수 단어 | 2,060 | 3,090 |
| 연구실 숙어 | 193 | 303 |
| 연구실 구동사 | 357 | 579 |
| 필수 문법 규칙 | 28 | 60 |

영어 연구실은 총 4,056개 자료를 포함합니다. 영어 5형식과 헷갈리는 표현도 기존 자료를 유지합니다. 토익 문법은 기존 **필수 문법 규칙** 안에서 실무 예문·한국어 해설·창작 선택형 문제 32개로 배웁니다. 비즈니스 영어를 위한 새 메뉴는 만들지 않았으며, 이메일·회의·계약·물류·인사·고객 대응 예문을 기존 단어장, 숙어, 구동사, 문법과 번역 연습에 섞었습니다.

사전과 연구실 단어는 서로 겹치는 자료가 있습니다. 둘의 합계를 서로 다른 단어 수로 표시하지 않습니다. 단어·표현 예문 수는 기본 60개, 기존 패턴 예문 10,000개, 새 비즈니스 패턴 예문 5,100개, 새 숙어·구동사 예문 332개를 합한 값입니다. 새 비즈니스 예문은 직접 작성한 170개 업무 행동에 30개 요청·계획·의무·간접의문문 패턴을 적용했습니다. 모든 사전 표제어에 예문이 있는 것은 아닙니다.

## 학습 기능

- 단어 뜻 맞히기, 문장 빈칸, 단어장 검색·저장, 직접 단어 추가
- 중급 중심 B1–B2 번역 3,000문장의 단어 카드 배열과 문장 전체 직접 입력
- 오늘의 학습에서 기존 단어 문제·번역 카드·직접 입력 혼합 출제
- 카드와 타이핑의 복습 일정을 따로 관리하고, 날짜별 기록에 함께 반영
- 미국 영어 남성 합성음성 Joe로 전체 3,000문장 듣기: 연속 재생, 반복, 섞기, 0.75–1.25배속
- 영어 연구실의 기존 6개 분류 및 한영 통합 검색, 문법 선택형 문제와 해설
- 기기 음성으로 단어·예문·한국어 문제 읽기
- 녹음과 다시 듣기, 발음 자가 점검, 외부 ChatGPT 연습 내용 복사
- 기록 JSON 백업·복원, PWA 설치, 오프라인 학습 자료 캐시

번역 문장은 반복 상황의 문법 변형을 없애고, 일상·여행·업무 등 서로 다른 메시지 3,000개로 다시 작성했습니다. 문장 길이는 평균 16.4단어에서 10.9단어로 약 33.7% 줄었으며, 도치·중첩절 대신 실용적인 기본 문장과 연결 표현을 사용합니다. B1–B2 표시는 편집상의 목표이며 공인된 난이도 측정값은 아닙니다. 카드와 타이핑은 같은 문장을 공유하므로 합쳐서 6,000개의 서로 다른 문장이라고 세지 않습니다. 직접 입력은 준비된 정답·허용 답안과 비교하며 모든 동의어를 이해하는 AI 의미 채점은 아닙니다. 같은 뜻의 자연스러운 번역은 사용자가 직접 정답으로 기록할 수 있습니다.

## 설치와 서버

Render Static Site가 파일을 제공하므로 개발용 맥북을 꺼도 접속할 수 있습니다. iPhone Safari에서 위 주소를 열고 공유 → 홈 화면에 추가를 선택하세요. 설치형 웹앱이며 App Store 앱은 아닙니다.

배포 설정: GitHub `main`, Root Directory 빈 값, Build Command `echo "Static files ready"`, Publish Directory `dist`, 환경변수 `SKIP_INSTALL_DEPS=true`. HTTP Headers의 `/audio/*.m4a`에 `Content-Type: audio/mp4`를 설정합니다. Python 서버나 `requirements.txt`는 배포에 필요하지 않습니다.

로컬 기본 미리보기는 저장소 루트에서 다음 명령으로 실행합니다. 음성의 문장별 탐색을 검증하려면 HTTP Range(206)를 지원하는 서버가 필요합니다.

```sh
python3 -m http.server 5867 --bind 127.0.0.1 --directory dist
```

## 기록과 오프라인

기존 `wordgarden-v1` 저장 형식, 단어 기록, 누적 학습 기록, 저장한 단어와 직접 추가한 단어를 유지합니다. 번역 문장이 교체되어 이전 카드·타이핑 복습 기록은 `translationArchives`에 보관하고 새 문장은 처음부터 학습합니다. 내보내는 백업에도 이 기록이 포함되며, 구버전 백업을 가져올 때도 같은 처리를 한 번 적용합니다. 기록은 해당 브라우저 localStorage에 저장되고 다른 기기에 자동 동기화되지 않습니다. 브라우저 데이터를 삭제하기 전 설정에서 백업하세요.

자료를 최초 저장하거나 업데이트할 때는 인터넷이 필요합니다. 캐시가 완료된 뒤 단어·숙어·문법·카드·타이핑 연습을 오프라인에서 이용할 수 있습니다. 기기가 사이트 데이터를 제거하면 다시 내려받아야 합니다.

Joe 음성은 50문장씩 묶은 AAC 파일 60개(약 87.6MB, 179.9분)를 필요할 때 스트리밍합니다. 새 문장은 `translation-audio-v2.json`과 `translation-v2-*.m4a`를 사용하며, 이전 화면을 열어 둔 사용자를 위해 기존 음성 파일과 목록도 유지합니다. 설치 시 전체 음성을 강제 다운로드하지 않습니다. 스트리밍은 인터넷이 필요하며, iPhone 화면 잠금·절전 상태에서는 연속 재생이 중단될 수 있습니다. 듣기 자체는 학습 완료로 세지 않습니다.

앱 내부 AI 챗봇이나 자동 음소·강세 채점은 포함하지 않습니다. 준비된 연습 내용을 복사하고 공식 ChatGPT를 열어 원하는 계정으로 대화하는 방식입니다. 계정 비밀번호·API 키·대화 내용을 단어정원에 입력하지 않습니다. 녹음은 메모리에만 보관하며 서버로 보내지 않습니다.

## 데이터와 이용 조건

- 사전: [Open English-Korean Dictionary](https://github.com/jhseo1211/open-english-korean-dict), CC BY-SA 4.0. 기존 A1–B2 자료에 추가 표제어를 선별하고 명백한 뜻 오류를 교정했습니다. CEFR·발음기호는 공개 자료를 바탕으로 하며 모든 항목을 독립적으로 인증한 것은 아닙니다.
- 연구실 원본: [나의 영어 연구실](https://my-toeic-english-lab.kohwoon-and-3040.chatgpt.site/). 기존 2,662개 자료의 필드와 순서를 보존했습니다. 새 예문·규칙을 뒤에 더했습니다.
- 새 어휘 예문 1,030개는 뜻과 문맥을 맞춰 직접 작성했습니다. 항목별 기록은 `dist/lab-example-sources.json`에 있습니다. 기존 연구실의 Tatoeba CC0 예문과 출처는 그대로 보존했습니다.
- 새 비즈니스 예문·숙어·구동사 예문·번역·토익형 문제는 이 앱을 위한 창작 자료입니다. 실제 TOEIC 문제를 복제하지 않았고 ETS와 제휴하지 않습니다.
- 음성: Piper 1.8.0 `en_US-joe-medium`, 원본 데이터셋 CC0, 모델 저장소 MIT. 로컬 합성 결과만 배포하며 유료 TTS API를 호출하지 않습니다.

전체 출처·라이선스: `dist/data-credits.html`, `dist/lab-attribution.txt`, `dist/translation-audio-attribution.txt`. 저장소 전체에 하나의 라이선스를 새로 부여하지 않았습니다.

## 주요 파일

`dist/app.js`는 단어·학습·복습·기록을, `lab.js`는 기존 연구실과 문법 문제를, `translation.js`는 카드·타이핑·연속 듣기를 담당합니다. `focus-theme.css`는 새 디자인입니다. `dictionary-data.json`, `lab-data.json`, `translation-data.json`은 앱에 포함된 자료와 동일한 다운로드용 데이터입니다. `content-expansion-info.json`은 확장 전후 개수와 출처를 기록합니다. `sw.js`는 앱 자료의 오프라인 캐시를 갱신합니다.

루트의 `work-dictionary.py`와 `work-expand.py`는 초기 생성 이력용이며 반복 실행용 빌드 명령이 아닙니다. 실행하면 현재 앱 파일을 덮어쓸 수 있으므로 일반 사용 시 실행하지 마세요.
