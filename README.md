# 단어정원 · Word Garden

개인용 영어 단어·문장 학습 웹앱입니다. HTML, CSS, JavaScript로 작성되어 별도 빌드나 서버 API 없이 실행할 수 있습니다.

## 포함된 기능

- 영어 사전 표제어 6,000개 및 단어·표현을 합친 6,205개 항목
- 예문 10,060개, 전체 학습 문제 16,060개
- 뜻 맞히기, 문장 빈칸 퀴즈, 간격 반복 복습, 단어장, 학습 기록
- 직접 단어 추가, JSON 학습 기록 백업 및 복원
- 기기의 영어 음성을 사용한 단어·문장 재생
- 최대 30초 녹음과 다시 듣기, 발음 자가 점검
- 연습 상황과 수준을 선택해 ChatGPT에 붙여 넣을 연습 내용 생성
- 홈 화면 설치용 PWA 설정과 오프라인 자료 캐시

10,000개 확장 예문은 400개 단어·표현과 25개 문장 틀의 조합입니다. 모든 사전 단어에 예문이 연결되어 있는 것은 아닙니다. 공개 사전 번역은 전체 항목을 사람이 검수하지 않았습니다.

## 실행

Python 3가 있는 환경에서 저장소 루트에서 실행합니다.

```sh
python3 -m http.server 5867 --bind 127.0.0.1 --directory dist
```

브라우저에서 `http://127.0.0.1:5867/`을 엽니다. 기본 앱 사용에 패키지 설치, API 키, 회원가입은 필요하지 않습니다.

아이폰에서는 HTTPS로 게시된 주소를 Safari에서 연 뒤 공유 → 홈 화면에 추가를 사용합니다. 마이크와 서비스 워커는 보안 연결(HTTPS 또는 localhost)이 필요합니다. ZIP 파일을 아이폰에서 여는 것만으로 앱이 설치되지는 않습니다.

## 저장과 오프라인 사용

학습 기록은 해당 기기의 브라우저 localStorage에 저장됩니다. 자동 기기 간 동기화는 없습니다. 브라우저 데이터 삭제 전에 설정에서 백업하세요.

학습 자료의 최초 저장·업데이트에는 인터넷이 필요합니다. 자료가 캐시된 뒤에는 단어·예문 학습을 오프라인에서 사용할 수 있습니다. iOS가 사이트 데이터를 제거하면 다시 내려받아야 합니다. 발음 재생의 오프라인 지원은 설치된 영어 음성에 따라 달라집니다.

녹음은 메모리에서만 처리하며 서버로 보내지 않습니다. 학습 화면을 이동하면 녹음을 삭제합니다.

## AI와 발음 평가의 범위

이 버전에는 웹앱 내부 AI 챗봇이나 음소·강세를 분석하는 자동 발음 채점이 없습니다. 연습 내용을 복사하고 공식 ChatGPT 웹사이트를 열어 사용자가 같은 계정의 대화에 직접 붙여 넣는 방식입니다.

외부 AI API 키나 유료 API 연결을 포함하지 않습니다. ChatGPT 대화의 사용 한도·초과 과금 설정은 ChatGPT에서 별도로 관리되며, 이 앱은 그 사용량이나 과금을 제어하지 않습니다. 웹 호스팅 요금은 게시할 서비스의 조건을 따릅니다.

## 파일 구성

- `dist/`: 실행 가능한 정적 웹앱 전체
- `dist/app.js`: 단어장, 퀴즈, 복습, 기록, 설정
- `dist/practice.js`: 녹음·재생 및 ChatGPT 연습 안내
- `dist/sw.js`: 오프라인 캐시
- `dist/dictionary.js`, `dist/dictionary-data.json`: 가공 사전
- `dist/questions.js`: 확장 예문
- `dictionary-source.json`: 사전 변환에 사용한 원본 데이터
- `work-dictionary.py`, `work-expand.py`: 초기 자료 생성 및 코드 변환 작업 스크립트

작업 스크립트는 초기 생성 이력용이며 현재 앱 파일을 변경합니다. 앱 실행에는 필요하지 않고 반복 실행용 빌드 명령이 아닙니다. 일반 사용 시 실행하지 마세요.

기존 Sites의 프로젝트 연결 설정과 Git 인증정보는 이 소스 복사본에 포함하지 않았습니다. GitHub 업로드는 기존 사이트의 새 버전 배포를 수행하지 않습니다.

## 데이터 출처

사전 데이터 출처는 [Open English-Korean Dictionary](https://github.com/jhseo1211/open-english-korean-dict)입니다. A1–B2 표제어를 선별하고 일부 뜻을 수정했습니다. 가공 사전은 CC BY-SA 4.0 조건을 따릅니다. 자세한 상위 출처와 라이선스는 `dist/data-credits.html`을 확인하세요. 저장소 전체에 일괄적인 오픈소스 라이선스를 새로 부여하지 않았습니다.

## 확인한 범위

JavaScript 문법 검사, 390px 모바일 화면의 선택·복사 동작, 가상 오디오 장치의 녹음 종료·권한 거부·오류 처리, 로컬 서버 종료 후 재실행과 검색을 확인했습니다. 실제 아이폰 마이크와 홈 화면 설치는 별도 기기 확인이 필요합니다.
