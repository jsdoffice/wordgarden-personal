## 통합 문장 연습 · 2026-11-26

- 번역 연습 3,000문장과 생활영어 1,000문장은 한 연습 화면에서 **카드 배열 / 직접 입력**을 바꿔 풀 수 있습니다. 상단의 전체 방식은 기본값으로 저장하며, 문장별 선택은 현재 문장에만 적용합니다. 작성 중인 입력과 카드 선택·힌트는 방식 왕복 중 유지하고, 채점 후에는 방식을 잠가 한 번만 기록합니다.
- 문장 난이도는 전체 또는 1~5단계로 선택합니다. 문장 길이·어휘·문형으로 정한 앱 내부 분류이며 CEFR 인증값은 아닙니다. 전체 4,000문장 분포는 1단계 1,463 / 2단계 1,297 / 3단계 765 / 4단계 343 / 5단계 132개입니다. 생활영어는 기존 쉬운 자료를 보존해 1~3단계(696 / 260 / 44)에 분포합니다. 4~5단계 문장은 같은 단계의 VOA 번역 연습으로 연결합니다.
- 난이도는 해당 메뉴의 읽기·문제 풀이·연속 듣기에 함께 적용하며, 오늘의 학습도 선택한 단계의 문장을 출제합니다. 특정 자료에 문장이 없는 단계에서는 같은 단계의 다른 자료로 보완하고 기존 단어·문법 비율을 유지합니다. 전체 방식과 난이도는 기기 저장·백업에 포함됩니다.
- 직접 입력 오답은 입력한 문장 안의 다른 단어·오탈자·추가 단어를 빨간색과 밑줄로 표시하고, 빠진 표현은 별도로 보여줍니다. 허용 답안과 축약형·미영 철자 차이를 반영하는 예시 답안 비교이며, 의역을 의미로 평가하는 AI 채점은 아닙니다.
- 하단 9개 메뉴의 맨 위에 전체 반복듣기를 제공합니다. 학습 메뉴는 현재 필터의 자료를 재생하고, 홈·학습 기록·설정에서는 전체 4,000문장을 재생합니다. 문장은 기존 Michael 음원을, 단어·문법 예문은 기기 영어 음성을 사용합니다. 전체 반복과 한 문장 반복은 구분하며, 메뉴 전환·문제 시작 시 중단합니다.
- 첨부 이미지에서 추출한 주황 **#FFA64E**를 브랜드 색으로 적용했습니다. 따뜻한 밝은 배경, 읽기 쉬운 짙은 주황 글씨와 오류 표시용 빨강을 함께 사용합니다.
- 기존 영어·한국어 문장, 261개 음성 파일, 8,000개 방식별 진도 키와 백업 형식을 보존합니다. 저장 캐시는 `wordgarden-v33-sentence-hub-20261126-release`입니다.

## 모바일 화면 개편 · 2026-11-25

- 단어장·생활영어·번역 연습·문법·패턴 카드에서는 손가락을 따라 수평으로 움직이고, 놓으면 카드가 빠져나간 뒤 반대편에서 새 카드가 들어옵니다. 짧게 움직이거나 양끝에 도달하면 제자리로 돌아옵니다. 동작 줄이기 설정에서는 즉시 전환하며, 화면 이탈·필터 변경은 대기 중인 이동을 취소합니다.
- 토익 문법을 포함한 연구실 7개 분류의 카드에서는 핵심 설명과 기존 예문 전체를 한 본문에 표시합니다. 예문 탭은 없으며, 긴 내용은 같은 카드 안에서 위아래로 읽고 이전·다음 버튼은 고정합니다. 패턴 영어의 영한 예문 3개도 함께 표시합니다.
- 별도 말하기 화면과 연결 버튼을 제거했습니다. 발음 평가의 문장/단어에는 좌우 이동 모션과 이전·다음 버튼을 적용했습니다. 녹음 권한 요청·녹음·분석 중에는 문장을 바꾸지 않습니다. 오늘의 학습 문제는 채점 후 다음 버튼이나 왼쪽 스와이프로 이동하며, 미답변 문제는 넘어가지 않습니다.
- 홈의 목표 막대에는 오늘 푼 문제 수, 목표 달성률과 짧은 설명을 표시합니다. 목록의 기존 예문·번역은 펼침 동작 없이 바로 보입니다.
- 카드 본문과 하단 이동 영역에서 좌우 스와이프·짧은 플리킹으로 이동합니다. iPhone 터치 이벤트와 포인터 이벤트를 지원하며, 입력칸·세로 제스처·확대 제스처는 보호합니다.
- 상단 헤더를 제거하고 설정을 하단 메뉴로 옮겼습니다. 카드·목록 전환 버튼은 최소 높이 44px로 넓혔습니다.
- 아이폰 화면 크기에 맞춰 오늘의 학습 첫 화면과 문제·정답·다음 버튼을 한 화면 안에 배치합니다. 키보드가 열리면 하단 메뉴를 잠시 숨겨 입력칸과 제출 버튼의 공간을 확보하고, 제출 후 메뉴를 복원합니다. 긴 해설과 출처는 명시적인 도움/상세 버튼으로 엽니다.
- 서비스 표시 이름과 설치 아이콘을 **정보카**로 변경했습니다. 기존 설치 식별자, 학습 기록 저장 키와 백업 형식은 유지합니다.
- 하단의 9개 메뉴를 모두 표시하며, 휴대폰에서는 좌우 스크롤로 이동합니다. 홈 → 단어장 → 생활영어 → 번역 연습 → 문법·패턴 → 발음 평가 → 복습 → 학습 기록 → 설정 순서입니다.
- 단어장·문장·문법·패턴의 카드 보기에서는 화면 높이에 맞춰 한 장씩 보고, 이전/다음 버튼 또는 좌우 스와이프로 이동합니다. 목록 보기는 세로 스크롤을 허용합니다.
- 검색·필터와 추가 옵션은 버튼을 누를 때 열립니다. 단어장의 작은 화면용 예문 선택은 유지합니다.
- 콘텐츠, 오디오 파일과 복습 기록을 유지합니다. 현재 방식 선택과 저장 캐시는 위 통합 문장 연습 항목을 따릅니다.

번역 연습 3,000문장은 VOA Learning English 자체 제작 글 700편의 실제 영어 문장으로 교체했습니다. 생활·문화·과학·사회 등 다양한 주제에서 독립적으로 이해할 수 있는 짧은 문장을 선별하고 한국어 문제와 해설을 작성했습니다. 영어 정답은 원문 어순과 표현을 유지하며 공백과 인용부호만 정리했습니다. 문장 길이는 평균 10.7단어이고, 모든 문장을 원문 단락과 대조했습니다. 기존 666편을 모두 유지하고 새 글 34편의 문장 34개를 반영해 정확히 700편을 구성합니다. 이전 VOA 버전에서 문장이 같은 2,966개의 복습 기록은 유지하고 교체된 34개만 이전 기록을 백업에 보관합니다. B1–B2 표시는 편집상의 목표이며 공인된 난이도 측정값은 아닙니다. 카드와 타이핑은 같은 문장을 공유하므로 합쳐서 6,000개의 서로 다른 문장이라고 세지 않습니다. 직접 입력은 준비된 정답·허용 답안과 비교하며 모든 동의어를 이해하는 AI 의미 채점은 아닙니다. 같은 뜻의 자연스러운 번역은 사용자가 직접 정답으로 기록할 수 있습니다.

## 설치와 서버

### 발음 평가의 범위

새 **발음 평가** 메뉴는 문장 모드로 시작하며 단어 모드도 제공합니다. 마이크 녹음은 최대 20초이며 이 화면을 떠나면 삭제합니다. 녹음 원음이나 분석 결과를 서버에 전송하거나 계정에 저장하지 않습니다. 모델을 처음 준비할 때 공개 모델 파일을 내려받고, 실제 음소 인식은 Web Worker의 WebAssembly에서 실행합니다. 유료 API나 ChatGPT 계정 연결은 사용하지 않습니다. 번역·단어 복습 기록과 정답률은 바뀌지 않습니다.

문장 기준은 Michael 음성 제작에 사용한 미국 영어 표기를 보존하고, 단어 9,250개의 기준은 Misaki US 사전으로 다시 만들었습니다. 같은 철자의 여러 발음 192건을 허용하며 기존 사전 IPA의 약모음 오류를 평가 기준에 그대로 쓰지 않습니다. [기준 발음 출처](dist/hama/REFERENCE-NOTICE.txt)를 확인할 수 있습니다. Hama는 녹음에서 들린 소리만 추정합니다.

Hama v1.7.0은 영어 소리를 IPA 음소로 인식하는 실험적 모델입니다. 이전 소리 차이 표를 **100점 만점의 기준 소리 일치 점수와 음절별 great / good / soso / bad / worst**로 바꾸었습니다. 점수는 `반올림(100 × 일치 음소 수 / (기준 음소 수 + 추가로 인식된 음소 수))`이며 음절에도 같은 산식을 적용합니다. 등급 구간은 great 90–100, good 75–89, soso 55–74, bad 30–54, worst 0–29입니다. 이는 음성 인식의 일치 비율을 보여주는 앱 내부 연습 기준이며, 인간 평가로 보정된 발음 정확도·신뢰도가 아닙니다. 음절은 기준 IPA의 모음 핵과 영어 자음 연결 규칙으로 추정하며, 사전 철자 분절과 다를 수 있습니다. 추가 음소는 직전 음절(문장 맨 앞이면 첫 음절)에 포함합니다. 모음이 없는 소리는 종합 점수에만 포함합니다. 무음·큰 소음·클리핑·알 수 없는 인식 결과에는 점수 대신 재녹음 안내를 표시합니다. 발음이 자연스러워도 모델이 다르게 감지할 수 있습니다. 공식 공개 오류율은 LibriSpeech clean에서 10.94%, robust 시험에서 22.08%입니다. 한국어 화자의 영어 또는 iPhone 실기기에서 같은 정확도가 유지된다는 검증은 없습니다. 모델은 영어 주강세·부강세를 직접 출력하지 않으므로 **강세 정답/오답은 판정하지 않습니다.** 기준 음성과 자신의 녹음을 번갈아 듣고 소리 크기 흐름을 보면서 강세·리듬을 연습합니다. 파형의 크기는 음절 강세나 발음 정확도와 동일하지 않습니다.
