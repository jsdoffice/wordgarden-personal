# 단어정원 · Word Garden

아이폰 홈 화면에 설치할 수 있는 개인용 영어 학습 PWA입니다. 별도 로그인, 앱 서버, 유료 AI API 없이 동작합니다. 흰색·연회색 바탕, 선명한 파란색 강조, 큰 제목과 단순한 카드로 학습에 집중하도록 구성했습니다.

[단어정원 접속](https://wordgarden-personal-static.onrender.com/)

## 학습 콘텐츠

| 구분 | 이전 | 현재 |
|---|---:|---:|
| 사전 표제어 | 6,000 | 9,250 |
| 단어·표현 예문 | 10,060 | 15,492 |
| 한영 번역 문장 | 2,000 | 3,000 |
| 연구실 필수 단어 | 2,060 | 3,090 |
| 연구실 숙어 | 193 | 303 |
| 연구실 구동사 | 357 | 579 |
| 필수 문법 규칙 | 28 | 60 |

영어 연구실은 총 4,056개 자료를 포함합니다. 영어 5형식과 헷갈리는 표현도 기존 자료를 유지합니다. 토익 문법은 기존 **필수 문법 규칙** 안에서 실무 예문·한국어 해설·창작 선택형 문제 32개로 배웁니다. 비즈니스 영어를 위한 새 메뉴는 만들지 않았으며, 이메일·회의·계약·물류·인사·고객 대응 예문을 기존 단어장, 숙어, 구동사, 문법과 번역 연습에 섞었습니다.

사전과 연구실 단어는 서로 겹치는 자료가 있습니다. 둘의 합계를 서로 다른 단어 수로 표시하지 않습니다. 단어·표현 예문 수는 기본 60개, 기존 패턴 예문 10,000개, 새 비즈니스 패턴 예문 5,100개, 새 숙어·구동사 예문 332개를 합한 값입니다. 새 비즈니스 예문은 직접 작성한 170개 업무 행동에 30개 요청·계획·의무·간접의문문 패턴을 적용했습니다. 모든 사전 표제어에 예문이 있는 것은 아닙니다.

## 학습 기능

- 단어 뜻 맞히기, 문장 빈칸, 단어장 검색·저장, 직접 단어 추가
- 나의 단어장 목록·카드 보기: 미국식 발음기호, 품사·뜻, 카드 안 영한 예문 최대 3개, 이전·다음 이동. 검색과 필터는 모드를 바꿔도 유지합니다. 기본 60개에는 3개씩 예문을 갖추고, 연결된 예문이 없는 단어는 미등록으로 표시합니다. 직접 추가할 때 품사·발음기호·예문 번역도 입력할 수 있습니다.
- VOA 자체 제작 원문 기반 중급 중심 B1–B2 번역 3,000문장의 단어 카드 배열과 문장 전체 직접 입력
- 오늘의 학습에서 기존 단어 문제·번역 카드·직접 입력 혼합 출제
- 카드와 타이핑의 복습 일정을 따로 관리하고, 날짜별 기록에 함께 반영
- 미국 영어 남성 합성음성 Michael으로 전체 3,000문장 듣기: 연속 재생, 반복, 섞기, 0.75–1.25배속
- 영어 연구실의 기존 6개 분류 및 한영 통합 검색, 문법 선택형 문제와 해설
- 기기 음성으로 단어·예문·한국어 문제 읽기
- 녹음과 다시 듣기, 발음 자가 점검, 외부 ChatGPT 연습 내용 복사
- 문장 중심의 발음 평가 메뉴: VOA 3,000문장과 단어 모드, 기기 안에서 녹음·실험적 음소 비교
- 기록 JSON 백업·복원, PWA 설치, 오프라인 학습 자료 캐시

번역 연습 3,000문장은 VOA Learning English 자체 제작 글 700편의 실제 영어 문장으로 교체했습니다. 생활·문화·과학·사회 등 다양한 주제에서 독립적으로 이해할 수 있는 짧은 문장을 선별하고 한국어 문제와 해설을 작성했습니다. 영어 정답은 원문 어순과 표현을 유지하며 공백과 인용부호만 정리했습니다. 문장 길이는 평균 10.7단어이고, 모든 문장을 원문 단락과 대조했습니다. 기존 666편을 모두 유지하고 새 글 34편의 문장 34개를 반영해 정확히 700편을 구성합니다. 이전 VOA 버전에서 문장이 같은 2,966개의 복습 기록은 유지하고 교체된 34개만 이전 기록을 백업에 보관합니다. B1–B2 표시는 편집상의 목표이며 공인된 난이도 측정값은 아닙니다. 카드와 타이핑은 같은 문장을 공유하므로 합쳐서 6,000개의 서로 다른 문장이라고 세지 않습니다. 직접 입력은 준비된 정답·허용 답안과 비교하며 모든 동의어를 이해하는 AI 의미 채점은 아닙니다. 같은 뜻의 자연스러운 번역은 사용자가 직접 정답으로 기록할 수 있습니다.

## 설치와 서버

### 발음 평가의 범위

새 **발음 평가** 메뉴는 문장 모드로 시작하며 단어 모드도 제공합니다. 마이크 녹음은 최대 20초이며 이 화면을 떠나면 삭제합니다. 녹음 원음이나 분석 결과를 서버에 전송하거나 계정에 저장하지 않습니다. 모델을 처음 준비할 때 공개 모델 파일을 내려받고, 실제 음소 인식은 Web Worker의 WebAssembly에서 실행합니다. 유료 API나 ChatGPT 계정 연결은 사용하지 않습니다. 번역·단어 복습 기록과 정답률은 바뀌지 않습니다.

문장 기준은 Michael 음성 제작에 사용한 미국 영어 표기를 보존하고, 단어 9,250개의 기준은 Misaki US 사전으로 다시 만들었습니다. 같은 철자의 여러 발음 192건을 허용하며 기존 사전 IPA의 약모음 오류를 평가 기준에 그대로 쓰지 않습니다. [기준 발음 출처](dist/hama/REFERENCE-NOTICE.txt)를 확인할 수 있습니다. Hama는 녹음에서 들린 소리만 추정합니다.

Hama v1.7.0은 영어 소리를 IPA 음소로 인식하는 실험적 모델입니다. 기준 음소와 녹음에서 감지된 음소의 차이를 재확인할 후보로 표시하며, 이를 인간 평가에 보정한 발음 점수로 바꾸지 않습니다. 발음이 자연스러워도 모델이 다르게 감지할 수 있습니다. 공식 공개 오류율은 LibriSpeech clean에서 10.94%, robust 시험에서 22.08%입니다. 한국어 화자의 영어 또는 iPhone 실기기에서 같은 정확도가 유지된다는 검증은 없습니다. 모델은 영어 주강세·부강세를 직접 출력하지 않으므로 **강세 정답/오답은 판정하지 않습니다.** 기준 음성과 자신의 녹음을 번갈아 듣고 소리 크기 흐름을 보면서 강세·리듬을 연습합니다. 파형의 크기는 음절 강세나 발음 정확도와 동일하지 않습니다.

Safari 16.4 이후의 WASM SIMD와 현대적인 Worker·AudioContext 지원이 필요합니다. 기기 메모리나 브라우저 정책에 따라 분석이 실패할 수 있으며 재녹음과 녹음 다시 듣기를 제공합니다. 화면을 숨기거나 다른 메뉴로 이동하면 마이크와 분석 작업을 정리합니다. 전체 모델은 사용자 요청 시 준비하며 설치 시 전체 영어 음성 파일을 강제 다운로드하지 않습니다. 모델과 실행 파일의 출처·해시 및 라이선스 고지는 `dist/hama/NOTICE.txt`에 보존합니다. 저장소의 MIT 고지와 npm 패키지의 Apache-2.0 표기는 서로 다르므로 임의로 코드·모델 라이선스를 분리해서 단정하지 않습니다.

Render Static Site가 파일을 제공하므로 개발용 맥북을 꺼도 접속할 수 있습니다. iPhone Safari에서 위 주소를 열고 공유 → 홈 화면에 추가를 선택하세요. 설치형 웹앱이며 App Store 앱은 아닙니다.

배포 설정: GitHub `main`, Root Directory 빈 값, Build Command `echo "Static files ready"`, Publish Directory `dist`, 환경변수 `SKIP_INSTALL_DEPS=true`. HTTP Headers의 `/audio/*.m4a`에 `Content-Type: audio/mp4`를 설정합니다. Python 서버나 `requirements.txt`는 배포에 필요하지 않습니다.

로컬 기본 미리보기는 저장소 루트에서 다음 명령으로 실행합니다. 음성의 문장별 탐색을 검증하려면 HTTP Range(206)를 지원하는 서버가 필요합니다.

```sh
python3 -m http.server 5867 --bind 127.0.0.1 --directory dist
```

## 기록과 오프라인

기존 `wordgarden-v1` 저장 형식, 단어 기록, 누적 학습 기록, 저장한 단어와 직접 추가한 단어를 유지합니다. 기존 VOA 666편 버전에서 바뀐 34개 문장의 카드·타이핑 복습 기록만 `translationArchives`에 보관하고 새 문장은 처음부터 학습합니다. 바뀌지 않은 2,966개 문장의 복습 기록은 유지합니다. VOA 교체 이전 버전의 번역 기록은 전체를 보관한 뒤 현재 원문으로 새로 시작합니다. 내보내는 백업에도 이 기록이 포함되며, 구버전 백업을 가져올 때도 같은 처리를 한 번 적용합니다. 기록은 해당 브라우저 localStorage에 저장되고 다른 기기에 자동 동기화되지 않습니다. 브라우저 데이터를 삭제하기 전 설정에서 백업하세요.

자료를 최초 저장하거나 업데이트할 때는 인터넷이 필요합니다. 캐시가 완료된 뒤 단어·숙어·문법·카드·타이핑 연습을 오프라인에서 이용할 수 있습니다. 기기가 사이트 데이터를 제거하면 다시 내려받아야 합니다.

Michael 음성은 50문장씩 묶은 AAC 파일 60개(약 113.3MB, 232.5분)를 필요할 때 스트리밍합니다. 현재 음성은 `translation-audio-v5.json`과 새 `translation-v5-01.m4a`–`translation-v5-60.m4a`를 사용합니다. 3,000개 문장과 학습 revision은 바꾸지 않아 이번 음성 교체로 복습 기록을 초기화하지 않습니다. 이전 화면을 열어 둔 사용자를 위해 기존 Joe 음성 파일과 목록도 유지합니다. 설치 시 전체 음성을 강제 다운로드하지 않습니다. 스트리밍은 인터넷이 필요하며, iPhone 화면 잠금·절전 상태에서는 연속 재생이 중단될 수 있습니다. 듣기 자체는 학습 완료로 세지 않습니다.

앱 내부 AI 챗봇이나 강세 정답 채점은 포함하지 않습니다. 새 발음 메뉴는 기기 내에서 감지된 음소 차이를 참고용으로 비교합니다. 준비된 연습 내용을 복사하고 공식 ChatGPT를 열어 원하는 계정으로 대화하는 방식입니다. 계정 비밀번호·API 키·대화 내용을 단어정원에 입력하지 않습니다. 녹음은 메모리에만 보관하며 서버로 보내지 않습니다.

## 데이터와 이용 조건

- 사전: [Open English-Korean Dictionary](https://github.com/jhseo1211/open-english-korean-dict), CC BY-SA 4.0. 기존 A1–B2 자료에 추가 표제어를 선별하고 명백한 뜻 오류를 교정했습니다. CEFR·발음기호는 공개 자료를 바탕으로 하며 모든 항목을 독립적으로 인증한 것은 아닙니다.
- 연구실 원본: [나의 영어 연구실](https://my-toeic-english-lab.kohwoon-and-3040.chatgpt.site/). 기존 2,662개 자료의 필드와 순서를 보존했습니다. 새 예문·규칙을 뒤에 더했습니다.
- 새 어휘 예문 1,030개는 뜻과 문맥을 맞춰 직접 작성했습니다. 항목별 기록은 `dist/lab-example-sources.json`에 있습니다. 기존 연구실의 Tatoeba CC0 예문과 출처는 그대로 보존했습니다.
- 새 비즈니스 예문·숙어·구동사 예문·토익형 문제는 이 앱을 위한 창작 자료입니다. 실제 TOEIC 문제를 복제하지 않았고 ETS와 제휴하지 않습니다.
- 번역 원문: VOA Learning English 자체 제작 자료, 공개 도메인. [공식 재사용 안내](https://learningenglish.voanews.com/p/6861.html). 외부 통신사 기사·외부 인용·청취자 편지·사진·캡션은 제외합니다. 문장별 출처는 `dist/translation-data.json`, 기사별 작성자·날짜·링크는 `dist/translation-sources.json`에 있습니다. 한국어 번역과 해설은 앱을 위해 작성했으며 VOA의 공식 번역이 아닙니다. 영어 정답은 각 원문 단락과 대조했습니다.
- 현재 음성: Kokoro-82M v1.0 `am_michael` (Michael), 모델·음성 데이터 Apache-2.0, kokoro-onnx MIT. 로컬 합성 결과만 배포하며 유료 TTS API를 호출하지 않습니다. 선택 모델·voice 파일 해시와 보존한 원문 이용 조건은 `dist/audio/KOKORO-NOTICE.txt`에 있습니다.
- 구버전 음성: Piper 1.8.0 `en_US-joe-medium`, 원본 데이터셋 CC0, 모델 저장소 MIT. 이전 파일과 `dist/audio/ATTRIBUTION.txt`, `dist/audio/VOICE_MODEL_CARD.txt`는 기존 버전을 위해 그대로 보존합니다.

품사 표시는 기존 로컬 spaCy 3.8.0에 포함된 WordNet 3.0 lemma index와 굴절형 규칙, 기능어 및 기본 단어의 검수 표기를 사용합니다. 이는 가능한 품사 목록이며 원본의 통합 한국어 뜻을 품사별 정의로 나누지 않습니다. WordNet 전문은 `dist/wordbook-notice.txt`에 보존합니다. 기본 60개 발음은 음절 앞 강세 표기로 다듬고, 그 외 단어는 합성용 강세 표시를 생략했습니다. 발음기호는 교정된 Misaki 미국 영어 기준을 우선하며 새 표현도 같은 로컬 도구로 생성했습니다. 단어장 예문 120개를 새로 작성했으며 퀴즈 문제 수와 복습 기록은 바꾸지 않습니다.

전체 출처·라이선스: `dist/data-credits.html`, `dist/translation-attribution.txt`, `dist/lab-attribution.txt`, `dist/translation-audio-attribution.txt`. 저장소 전체에 하나의 라이선스를 새로 부여하지 않았습니다.

## 주요 파일

`dist/app.js`는 단어·학습·복습·기록을, `lab.js`는 기존 연구실과 문법 문제를, `translation.js`는 카드·타이핑·연속 듣기를 담당합니다. `focus-theme.css`는 새 디자인입니다. `dictionary-data.json`, `lab-data.json`, `translation-data.json`은 앱에 포함된 자료와 동일한 다운로드용 데이터입니다. `content-expansion-info.json`은 확장 전후 개수와 출처를 기록합니다. `sw.js`는 앱 자료의 오프라인 캐시를 갱신합니다.

루트의 `work-dictionary.py`와 `work-expand.py`는 초기 생성 이력용이며 반복 실행용 빌드 명령이 아닙니다. 실행하면 현재 앱 파일을 덮어쓸 수 있으므로 일반 사용 시 실행하지 마세요.
