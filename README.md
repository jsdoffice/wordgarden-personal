# 단어정원 · Word Garden

개인용 영어 단어·문장 학습 웹앱입니다. HTML, CSS, JavaScript로 작성되어 별도 빌드나 서버 API 없이 실행할 수 있습니다.

## 포함된 기능

- 영어 사전 표제어 6,000개 및 단어·표현을 합친 6,205개 항목
- 기존 예문 10,060개, 기존 학습 문제 16,060개
- 중상급 B2–C1 한국어→영어 번역 2,000문장: 무작위 단어 카드 배열과 문장 전체 직접 입력
- 오늘의 학습에 기존 단어 문제·번역 카드·직접 입력을 혼합 출제하고, 번역 두 모드의 복습 일정을 각각 관리
- 번역 2,000문장의 미국 영어 남성 합성음성 Joe: 연속 듣기, 문장 반복, 무작위 재생, 0.75–1.25배속
- 뜻 맞히기, 문장 빈칸 퀴즈, 간격 반복 복습, 단어장, 학습 기록
- 직접 단어 추가, JSON 학습 기록 백업 및 복원
- 기기의 영어 음성을 사용한 단어·문장 재생
- 최대 30초 녹음과 다시 듣기, 발음 자가 점검
- 연습 상황과 수준을 선택해 ChatGPT에 붙여 넣을 연습 내용 생성
- 홈 화면 설치용 PWA 설정과 오프라인 자료 캐시
- 영어 연구실 전체 자료 2,662개: 필수 단어 2,060개, 숙어 193개, 구동사 357개, 영어 5형식 8개, 헷갈리는 표현 16개, 문법 규칙 28개
- 영어 연구실의 한영 통합 검색, 발음기호·영어 뜻풀이·예문, 문장 구조 설명, 비교표와 맞는/틀린 문장

10,000개 확장 예문은 400개 단어·표현과 25개 문장 틀의 조합입니다. 모든 사전 단어에 예문이 연결되어 있는 것은 아닙니다. 공개 사전 번역은 전체 항목을 사람이 검수하지 않았습니다.

영어 연구실은 [나의 영어 연구실](https://my-toeic-english-lab.kohwoon-and-3040.chatgpt.site/)의 6개 분류 전체를 통합한 자료실입니다. 기존 단어장과 단어가 겹쳐도 뜻·예문·설명을 생략하지 않도록 별도 메뉴에서 제공합니다. 연구실 자료 2,662개는 기존 퀴즈 16,060개와 별도로 집계합니다. 기존 `wordgarden-v1` 학습 기록과 백업 형식은 유지됩니다.

번역 문항은 200개 상황에 70가지 문법 구문을 적용한 2,000개의 서로 다른 한영 문장 쌍입니다. 카드 배열 2,000개와 직접 입력 2,000개가 같은 문장을 공유하며, 각각 `tr`/`tt` ID로 학습합니다. 모드별 과제를 합치면 기존 문제 포함 20,060개이며 서로 다른 번역 문장 수는 2,000개입니다. 직접 입력은 예시·허용 답안과 비교하는 결정적 채점입니다. 대소문자·문장부호와 일부 축약형을 정규화하지만 모든 동의어·자유 번역을 이해하는 AI 채점은 아닙니다. 같은 뜻의 다른 번역은 예시와 비교한 뒤 직접 정답으로 기록할 수 있습니다.

## 게시 주소와 Render 배포

[단어정원 접속](https://wordgarden-personal-static.onrender.com/)

Render **Static Site**에서 저장소 `main` 브랜치, Root Directory 빈 값, Build Command `echo "Static files ready"`, Publish Directory `dist`, 환경변수 `SKIP_INSTALL_DEPS=true`로 배포합니다. 별도 Python 서버나 `requirements.txt`가 필요하지 않습니다. 기존 Python Web Service와 별개의 정적 사이트입니다.

앱 업데이트 시 서비스 워커가 새 자료를 캐시에 저장합니다. 이전 화면이 계속 보이면 인터넷에 연결한 상태로 앱을 다시 열거나 새로고침하세요. 학습 기록을 지우기 위해 사이트 데이터를 삭제할 필요는 없습니다.

## 실행

Python 3가 있는 환경에서 저장소 루트에서 실행합니다.

```sh
python3 -m http.server 5867 --bind 127.0.0.1 --directory dist
```

브라우저에서 `http://127.0.0.1:5867/`을 엽니다. 기본 앱 사용에 패키지 설치, API 키, 회원가입은 필요하지 않습니다.

아이폰에서는 HTTPS로 게시된 주소를 Safari에서 연 뒤 공유 → 홈 화면에 추가를 사용합니다. 마이크와 서비스 워커는 보안 연결(HTTPS 또는 localhost)이 필요합니다. ZIP 파일을 아이폰에서 여는 것만으로 앱이 설치되지는 않습니다.

## 저장과 오프라인 사용

학습 기록은 해당 기기의 브라우저 localStorage에 저장됩니다. 자동 기기 간 동기화는 없습니다. 브라우저 데이터 삭제 전에 설정에서 백업하세요.

학습 자료의 최초 저장·업데이트에는 인터넷이 필요합니다. 자료가 캐시된 뒤에는 단어·예문 학습을 오프라인에서 사용할 수 있습니다. iOS가 사이트 데이터를 제거하면 다시 내려받아야 합니다. 발음 재생의 오프라인 지원은 설치된 영어 음성에 따라 달라집니다.

번역 카드·직접 입력과 해설도 앱 캐시에 포함합니다. Joe 음성은 50문장씩 묶은 AAC 파일 40개를 필요할 때 스트리밍하며, 전체 음성을 설치 시 강제 저장하지 않습니다. 이 음성의 연속 듣기는 인터넷이 필요합니다. 듣기는 학습 완료로 집계하지 않습니다. iPhone의 화면 잠금·절전 상태에서는 연속 재생이 중단될 수 있습니다. 한국어 문장 듣기는 기기의 한국어 음성을 사용합니다.

녹음은 메모리에서만 처리하며 서버로 보내지 않습니다. 학습 화면을 이동하면 녹음을 삭제합니다.

## AI와 발음 평가의 범위

이 버전에는 웹앱 내부 AI 챗봇이나 음소·강세를 분석하는 자동 발음 채점이 없습니다. 연습 내용을 복사하고 공식 ChatGPT 웹사이트를 열어 원하는 계정의 대화에 직접 붙여 넣는 방식입니다. 현재 계정과 다른 새 계정도 ChatGPT에서 로그인해 사용할 수 있습니다. 단어정원은 계정 토큰이나 대화를 읽지 않습니다.

2026-10-30 확인한 [Sign in with ChatGPT 공식 안내](https://developers.openai.com/siwc/token-sharing-open-source)에 따르면, 공개된 구독 한도 연동 절차는 오픈소스·로컬 앱 중심이며 원격 호스팅 앱은 별도 접근 승인이 필요합니다. 현재 Render 정적 사이트에 작동하지 않는 OAuth 연동을 표시하거나 계정 비밀번호/API 키를 받지 않습니다.

외부 AI API 키나 유료 API 연결을 포함하지 않습니다. ChatGPT 대화의 사용 한도·초과 과금 설정은 ChatGPT에서 별도로 관리되며, 이 앱은 그 사용량이나 과금을 제어하지 않습니다. 웹 호스팅 요금은 게시할 서비스의 조건을 따릅니다.

## 파일 구성

- `dist/`: 실행 가능한 정적 웹앱 전체
- `dist/app.js`: 단어장, 퀴즈, 복습, 기록, 설정
- `dist/practice.js`: 녹음·재생 및 ChatGPT 연습 안내
- `dist/sw.js`: 오프라인 캐시
- `dist/dictionary.js`, `dist/dictionary-data.json`: 가공 사전
- `dist/questions.js`: 확장 예문
- `dist/lab-data.js`, `dist/lab-data.json`: 원본 필드를 보존한 영어 연구실 전체 자료와 6개 분류 설명
- `dist/lab.js`, `dist/lab.css`: 통합 자료실 검색·분류·상세 콘텐츠 화면
- `dist/lab-attribution.txt`: 영어 연구실 원본 출처와 이용 조건 전문
- `dist/translation-data.js`, `dist/translation-data.json`: 번역 2,000문장과 허용 답안·문법 해설
- `dist/translation.js`, `dist/translation.css`: 카드 배열, 직접 입력, 연속 듣기
- `dist/translation-audio.json`, `dist/audio/*.m4a`: 미국 영어 남성 음성의 문장별 재생 구간과 파일
- `dist/translation-audio-attribution.txt`: 합성음성의 모델·데이터 출처
- `dictionary-source.json`: 사전 변환에 사용한 원본 데이터
- `work-dictionary.py`, `work-expand.py`: 초기 자료 생성 및 코드 변환 작업 스크립트

작업 스크립트는 초기 생성 이력용이며 현재 앱 파일을 변경합니다. 앱 실행에는 필요하지 않고 반복 실행용 빌드 명령이 아닙니다. 일반 사용 시 실행하지 마세요.

기존 Sites의 프로젝트 연결 설정과 Git 인증정보는 이 소스 복사본에 포함하지 않았습니다. GitHub 업로드는 기존 사이트의 새 버전 배포를 수행하지 않습니다.

## 데이터 출처

사전 데이터 출처는 [Open English-Korean Dictionary](https://github.com/jhseo1211/open-english-korean-dict)입니다. A1–B2 표제어를 선별하고 일부 뜻을 수정했습니다. 가공 사전은 CC BY-SA 4.0 조건을 따릅니다. 자세한 상위 출처와 라이선스는 `dist/data-credits.html`을 확인하세요. 저장소 전체에 일괄적인 오픈소스 라이선스를 새로 부여하지 않았습니다.

영어 연구실에 포함된 추가 사전, 구동사·숙어의 영어 뜻풀이와 Tatoeba 예문의 출처 및 CC BY-SA 4.0 / MIT / The Unlicense / CC0 이용 조건은 `dist/lab-attribution.txt`에 원문 그대로 보존했습니다.

번역 음성은 Piper 1.8.0의 `en_US-joe-medium` 모델로 로컬에서 생성했습니다. 원본 음성 데이터셋은 Open Home Foundation / Nabu Casa의 CC0 자료입니다. 음성 생성 프로그램이나 모델 파일 자체는 웹앱에 포함하지 않습니다. 영어 문장 음성은 사람의 신규 녹음이 아닌 합성음성입니다.

## 확인한 범위

JavaScript 문법 검사, 390px 모바일 화면의 선택·복사 동작, 가상 오디오 장치의 녹음 종료·권한 거부·오류 처리, 로컬 서버 종료 후 재실행과 검색을 확인했습니다. 실제 아이폰 마이크와 홈 화면 설치는 별도 기기 확인이 필요합니다.

영어 연구실 통합 시 원본 2,662개 항목의 모든 필드와 순서, 다운로드 JSON, 출처 전문을 대조했습니다. 6개 분류, 통합 검색·강조, 더 보기, 390px 화면과 서버 종료 후 연구실 검색을 확인했습니다. 기존 퀴즈 데이터와 학습 기록 저장 형식은 변경하지 않았습니다.

## 번역 기능 검증

2,000개 한영 문장 쌍의 고유 ID·중복·필수 필드, 1,950개 허용 답안, 오늘의 학습 세 유형 혼합, 모드별 복습과 기존 기록 유지, 중복 제출 방지를 검사했습니다. AAC 40개(약 105.5 MB, 216.9분)를 다시 디코딩해 2,000개 재생 구간의 음량과 시간을 검증했습니다. 브라우저에서 카드 정답, 직접 입력 정답과 다른 번역의 수동 인정, 날짜별 집계, 연속 재생과 문장 전환, 390px 화면을 확인했습니다. 로컬 서버를 종료한 뒤에도 앱을 다시 열고 직접 입력을 채점했습니다. 실제 iPhone 기기에서의 장시간 잠금 화면 재생은 검증하지 않았습니다.

Render HTTP Headers에는 `/audio/*.m4a` → `Content-Type: audio/mp4`를 설정했습니다. 음성 문장 이동은 서버의 HTTP Range(206) 응답을 사용합니다. 로컬 음성 재생 검증에도 Range 지원 서버를 사용해야 합니다.

디자인은 옅은 파란색 바탕과 진한 파란색 버튼·글자로 통일했습니다. 설치 아이콘과 브라우저 테마 색상도 함께 갱신했습니다.
